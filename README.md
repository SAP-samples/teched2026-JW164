# JW164 - Joule Work mobile app: Your company's AI-native mobile experience


[![REUSE status](https://api.reuse.software/badge/github.com/SAP-samples/teched2026-JW164)](https://api.reuse.software/info/github.com/SAP-samples/teched2026-JW164)

## Description

This repository contains the material for the SAP TechEd 2026 session called **JW164 - Joule Work mobile app: Your company's AI-native mobile experience**.

## Overview

Discover the Joule Work mobile app and its features across supported experiences. In the first half of this hands-on you connect the app to an existing **SAP Build Work Zone, advanced edition** site and explore what it offers for your day-to-day work: your apps from SAP S/4HANA Cloud, an extension app with a UI Integration Card, Workspaces, and Joule. In the second half you connect the same app to **Joule Work** and explore how it serves as the foundation for your company's transition to an AI-native mobile experience.

> [!NOTE]
> The Joule Work mobile app was formerly known as **SAP Mobile Start**. It was rebranded with version 3.0. All the Work Zone capabilities you may know from SAP Mobile Start remain available, and the app now additionally connects to Joule Work.

## Requirements

The requirements to follow the exercises in this repository are:

- A smartphone or tablet (iOS or Android) capable of running the Joule Work mobile app
- A desktop browser (provided at your workshop desk)
- A user and password provided by the instructors

If you run these exercises outside of the SAP TechEd 2026 session, you additionally require access to an SAP Build Work Zone, advanced edition site and a Joule Work tenant.
